## M8_V01_Why_Language_and_Vision_After_Perception_[F]

### Purpose

Introduce Module 8 as model-assisted visual pick-and-place.

### Story question

> If the robot can already use RGB-D perception, can we use a language or vision-language model to choose what object it should pick?

### Content

* Review Module 6 perception.
* Explain that the model is not controlling joints.
* Explain that the model helps identify the visual target.
* Explain the final goal:

```text
instruction
→ visual target
→ VLM detection
→ depth pose
→ pick/place executor
```

### Output

Students understand that Module 8 is visual robot action using LLM/VLM assistance.

## M8_V02_LLM_VLM_VLA_Mental_Model_[A]

### Purpose

Teach the difference between LLM, VLM, and VLA in a robotics context.

### Story question

> What does the model understand, what does the camera see, and what does the robot execute?

### Content

Explain:

```text
LLM:
understands text instructions

VLM:
looks at an image and identifies objects or image regions

VLA:
connects vision and language to robot action at a high level
```

Clarify:

```text
In this module, we are not training a VLA model.
We are using VLM detection plus RGB-D geometry to produce a robot target pose.
```

Visual flow:

```text
Instruction
→ object prompt
→ VLM object detection
→ depth pose estimation
→ visual pick/place
```

### Output

Students understand the model roles without confusing them with robot control loops.


Explain:

```text

```

```text

```
