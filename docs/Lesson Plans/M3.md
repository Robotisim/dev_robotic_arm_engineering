## M3_V01_From_Joint_Space_to_Task_Space_[F]

### Purpose

Introduce the shift from joint control to end-effector control.

### Story question

> Instead of moving joints manually, how do we make the gripper reach a target?

### Content

Explain:

* joint space
* task space
* end-effector
* target pose
* why IK is needed
* why Module 2 FK prepares us for Module 3

Use this comparison:

```text
Joint control: move these joints
Task-space control: move the gripper here
```

### Output

Students understand why IK is needed.

## M3_V04_The_Motion_Demo_Pipeline_[S]

### Purpose

Explain the common architecture behind all motion demos.

### Story question

> What happens inside a Cartesian motion demo before the robot moves?

### Content

Explain the shared pipeline:

```text
read joint states
create Cartesian path
validate workspace
solve IK per waypoint
publish RViz markers
publish JointTrajectory
report status
```

Use these files conceptually:

* `demo_base.py`
* `panda_kinematics.py`
* `trajectory_utils.py`

The teaching map identifies `demo_base.py` as the best file to explain the full pipeline and `panda_kinematics.py` as the mathematical heart of Module 3.

### Output

Students understand the full Cartesian-to-joint trajectory pipeline.
